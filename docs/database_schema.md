# Database Schema (Supabase / PostgreSQL)

This document outlines the core tables and relationships for the Real Estate SaaS MVP. The database relies heavily on PostgreSQL's Row Level Security (RLS) to manage permissions between Users, Owners, and Admins.

## Core Tables

### 1. `users` (Managed via Supabase Auth)
Stores core authentication identity.
- `id`: uuid (PK, references auth.users)
- `email`: varchar
- `created_at`: timestamp

### 2. `profiles`
Extended profile information for all users.
- `id`: uuid (PK, references users.id)
- `full_name`: varchar
- `phone_number`: varchar
- `role`: enum ('USER', 'OWNER', 'ADMIN', 'SUPER_ADMIN')
- `avatar_url`: varchar
- `created_at`: timestamp
- `updated_at`: timestamp

### 3. `properties`
The core property listings.
- `id`: uuid (PK)
- `owner_id`: uuid (FK -> profiles.id)
- `title`: varchar
- `description`: text
- `property_type`: enum ('APARTMENT', 'HOUSE', 'VILLA', 'COMMERCIAL')
- `listing_type`: enum ('SALE', 'RENT')
- `price`: numeric
- `area_sqft`: numeric
- `bedrooms`: integer
- `bathrooms`: integer
- `furnishing_status`: enum ('FURNISHED', 'SEMI_FURNISHED', 'UNFURNISHED')
- `address`: varchar
- `latitude`: numeric
- `longitude`: numeric
- `status`: enum ('DRAFT', 'PENDING_APPROVAL', 'PUBLISHED', 'PAUSED', 'REJECTED', 'SOLD_RENTED')
- `created_at`: timestamp
- `updated_at`: timestamp

### 4. `property_media`
Images and videos associated with a property.
- `id`: uuid (PK)
- `property_id`: uuid (FK -> properties.id)
- `url`: varchar
- `media_type`: enum ('IMAGE', 'VIDEO')
- `is_featured`: boolean
- `display_order`: integer
- `created_at`: timestamp

### 5. `enquiries`
Leads generated by users interested in a property.
- `id`: uuid (PK)
- `property_id`: uuid (FK -> properties.id)
- `user_id`: uuid (FK -> profiles.id) -- The user making the enquiry
- `owner_id`: uuid (FK -> profiles.id) -- Denormalized for easier querying
- `message`: text
- `status`: enum ('NEW', 'READ', 'RESPONDED', 'CLOSED')
- `created_at`: timestamp
- `updated_at`: timestamp

### 6. `saved_properties` (Favorites)
- `id`: uuid (PK)
- `user_id`: uuid (FK -> profiles.id)
- `property_id`: uuid (FK -> properties.id)
- `created_at`: timestamp

## Row Level Security (RLS) Principles
- **Properties**: 
  - `SELECT`: Anyone can view if `status = 'PUBLISHED'`. Owners can view their own regardless of status. Admins can view all.
  - `INSERT/UPDATE`: Owners can insert/update where `owner_id = auth.uid()`.
- **Enquiries**:
  - `SELECT`: Owners can see enquiries where `owner_id = auth.uid()`. Users can see enquiries they created (`user_id = auth.uid()`).
- **Profiles**:
  - `SELECT`: Public.
  - `UPDATE`: Users can update their own profile.
